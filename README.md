# NumPy Sales Analysis

## Project Overview

This project focuses on analyzing a sales dataset using NumPy and Pandas.

The main goal of the project is to strengthen fundamental NumPy concepts by applying them to a real-world sales dataset.

## Objectives

* Understand NumPy arrays
* Convert Pandas columns into NumPy arrays
* Perform numerical calculations
* Calculate total sales, profit, and quantity
* Calculate average transaction metrics
* Identify minimum and maximum values
* Use `np.argmax()` and `np.argmin()`
* Understand NumPy indexing
* Connect NumPy results back to a Pandas DataFrame
* Extract basic business insights

## Dataset

The dataset contains 1,194 sales transactions and includes information such as:

* Order ID
* Amount
* Profit
* Quantity
* Category
* Sub-Category
* Payment Mode
* Order Date
* State
* City
* Year-Month
